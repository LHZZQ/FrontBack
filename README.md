# 多人前后排 Mod · v0.3.5 实验原型

支持《杀戮尖塔2》2–4 人联机。战斗中点击队友状态旁的「⇄ 队伍站位」，使用头像拖放和快捷按钮调整队形。默认前排承受怪物攻击伤害 150%，中排 100%，后排 50%。

**当前状态：v0.3.2 在游戏内测过的功能均正常。「拦截」意图修复、奥斯提血条遮挡修复和宠物跟随主人换排仍待游戏内实测。**

## 安装

退出游戏，解压 `FrontBack-v0.3.5.zip`，将解压得到的 `FrontBack` 文件夹放入游戏安装目录下的 `mods` 文件夹。升级时，用新版 `FrontBack.dll` 和 `FrontBack.json` 替换旧文件，可保留现有的 `FrontBack.config.json`。联机前请确认所有玩家都更新到同一版本。

## 1. 本机环境

- 游戏路径：`D:\steam\steamapps\common\Slay the Spire 2`
- `release_info.json`：`v0.113.1`，commit `d09d48e5`，2026-11-14。
- Steam：`public-beta` 分支，build ID `26660232`。
- 游戏使用 .NET 9；本机 SDK 为 .NET 10.0.402，可以编译 net9.0。
- 自动检查使用项目内 `.tools/runtime9` 的 .NET 9.0.7，与本机游戏一致。
- 直接引用游戏自带的 `sts2.dll`、`GodotSharp.dll`、`0Harmony.dll`。**玩家无需安装 BaseLib、KitLib、RitsuLib 或其他前置 Mod。** 所有联机玩家需要相同版本的游戏和本 Mod。

社区模板可以参考，但接口以本机程序集核对结果为准。升级游戏后必须重新编译和测试。

## 2. 已落实的规则

- 新开一局时全员站中排，保留原版人物布局。两人还可选 1 前 1 后，三人还可选 1 前 2 后，四人还可选 1 前 2 中 1 后或 2 前 2 后。
- 可出牌且存活的玩家可发起换位和切换阵型，次数不限。拖动自己的头像到队友头像上可以互换。缺少目标排时，「我去前／中／后排」会切到包含该排的阵型。
- 怪物原本攻击谁保持原样；前排不负责自动承接后排的攻击。
- 阵型和站位会延续到下一场战斗。房主本地保存阵型，续玩同一存档时恢复，开战时把站位和倍率发给所有玩家。
- 换位经房主排序后同步执行。战斗中的金、灰、蓝徽章分别表示前、中、后排，也可随时展开队伍板确认。

- 站位徽章只在战斗画面处于前台时显示。打开搜刮、抽牌堆、弃牌堆、消耗堆、卡牌详情或地图时会隐藏，地图收起动画结束后再恢复。
- 换排后，怪物头顶的攻击意图会刷新，显示格挡前的预计伤害。受到「拦截」掩护时，显示队友替你接下的那一份，按队友的站位计算。
- 只对怪物造成、原始目标为玩家、带 `Move` 标记的正常攻击生效。自伤、毒等生命流失、非攻击效果及直接打向宠物的伤害保持原版。
- 先执行原版加算和乘算，再乘站位倍率，再执行原版伤害上限，最后由游戏处理格挡、重定向和取整。已计算后仅执行 Cap 的伤害不会重复乘算。
- 示例：怪物正常攻击 20、玩家有 8 点格挡，前排扣血 `30-8=22`，后排扣血 `10-8=2`。无格挡时，后排受到 5 点攻击，游戏最终扣 2 点血。
- UI 移动整个 `NCreature`，不只移动立绘；使用原版计算的左右落点并增加纵向错位，宠物跟随所属玩家的位移。
- 战斗画面中，本机奥斯提的血条绘制在角色立绘上方，回合内召唤时立即生效。

## 3. 按文件逐步读 C#

1. `src/FrontBack/Formation.cs`：记录各玩家站位，验证 2–4 人的阵型组合，并提供各排的伤害倍率。
2. `DamagePatch.cs`：Harmony 向游戏原伤害方法插入一次倍率计算。保留小数交给原版结算，避免提前取整。
3. `SwapAction.cs`：按钮不直接改状态，而是把“请求换位”包装成 `GameAction`。`NetSwapAction.Serialize` 写入回合信息，另一端 `Deserialize` 读出，随后由游戏动作队列执行。旧回合请求会被拒绝。
4. `CombatOverlay.cs`：创建可展开的队伍板，接收头像拖放和快捷按钮操作。
5. `FormationVisuals.cs`：展示站位徽章，并按换排带来的位移差移动人物，尽量保留外部效果的位移。
6. `SavedRanks.cs`：将房主的队伍站位保存到本机游戏用户目录。

## 4. 配置和重新编译

游戏内打开 **设置 → 常规 → 前后排伤害设置 → 打开设置**（位于常规设置列表底部），分别输入前排、后排百分比后点击“保存”。支持 0–10000%，精确到 0.1%；100% 为原版伤害，0% 为免除此类怪物攻击伤害。可恢复默认 150% / 50%。

v0.2.1 使用原版设置项的名称与绿色按钮布局，弹窗按钮复用原版外观和交互效果。两个输入框只编辑数字，右侧 `%` 为独立固定标签，聚焦和编辑时始终显示。

每场多人战斗开始前，使用游戏原生玩家选择通道同步房主设置和队伍站位。保存新数值从下一场战斗开始生效。客机可以为自己以后当房主保存偏好。

伤害设置保存在游戏用户数据目录的 `mod_data/FrontBack/damage-settings.json`。`FrontBack.config.json` 里的 `RowOffsetY` 控制上下错位距离，`SwapAnimationSeconds` 控制动画秒数。修改后重启。

需要重新编译时，在项目目录的 PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\Check.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\Package.ps1
```

首次还原依赖需要联网。如果换电脑，需安装 .NET SDK 与 .NET 9 运行环境，或重新准备项目内运行环境。`Check.ps1` 优先使用 `.tools/runtime9/dotnet.exe`；不要用 .NET 10 执行游戏的旧 Harmony。游戏路径不同时，给 Build/Check 传 `-GameDir '你的游戏目录'`。

输出包不含游戏程序集、游戏资源或测试工具。`local.props.example` 可复制为 `local.props` 后设置自己的路径。
